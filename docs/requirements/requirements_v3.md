# 日观声记 · 完整需求文档 v3

> 本文档将 `requirements_v1.md`（产品设计初稿）与 `requirements_v2.md`（需求澄清结果）合并为一份自洽完整的需求规格说明书。

---

## 一、产品目标

为个人记录流水账日记。任何时候想起来都可以对着软件说几句，晚上再系统地总结一次。

核心承诺：

- **声音必须保存**
- **语音自动转为文字**
- **每天整理成一份文字稿**（远期目标，本期不实现，详见第八章）

---

## 二、核心实体

### 2.1 碎片记录（Fragment Record）

> 代表「发生过的事实」，是每次说话的原始输入。

- **包含**：录音时间、原始音频文件（MP3）、语音直转的原始文字
- **特性**：只读、只增不改；转出来的文字不管多乱，原样保留

### 2.2 每日文字稿（Daily Journal）

> 代表「整理后的日记」，是当天所有碎片记录的加工结果。**本期 MVP 不实现，仅保留概念定义供下一期使用。**

- **包含**：日期、经大模型润色排版后的通顺文字
- **特性**：可反复覆盖生成，但**必须保留所有历史版本**（追加式存储，旧版本不丢）

---

## 三、运作流程

### 3.1 本期 MVP 流程

```
随时录音  →  上传 OSS  →  本地下载  →  Whisper 转写  →  保存文字
```

1. **随时随地记录**：在小程序里点一下开始、再点一下结束；支持长时间录音；录完支持试听、重录、删除
2. **可靠上传**：录音文件先落盘到小程序本地缓存，再异步上传到阿里云 OSS；上传成功后才允许从本地清理（保留约 2 天兜底）
3. **本地拉取**：家里 Mac Studio 上的 Python 脚本轮询 OSS，把新文件下载到本地（**不删除云端文件**，OSS 作为长期备份）
4. **本地转写**：使用模型将语音转写为文字，保存为文本文件，与音频文件一一对应

### 3.2 下一期流程（保留，本期不做）

```
... → 凌晨 05:00 自动整理 → 大模型润色 → 保存当日文字稿（保留历史版本）
```

## 四、设计原则

- **随时可用，方便快捷**：日常记录时必须保证极低摩擦
- **极薄前端 + 核心后端**：前端只负责采集，后端负责业务与存储
- **数据零丢失**：从录音到云端备份，每一段音频都必须有完整闭环
- **不允许虚构事实**：未来 LLM 润色阶段，**绝对禁止「添油加醋」和虚假事实**

---

## 五、本期 MVP 范围

### 5.1 本期要跑通的最小流程

录音 → 上传 OSS → 本地下载 → Whisper 转写 → 保存为文本文件

### 5.2 数据存储方式

**不使用 SQLite**，整个流程**纯文件管理**：音频文件 + 转写文本文件，按目录组织。

### 5.3 本期**不做**的事

- LLM 润色与日稿生成
- 日稿的呈现界面
- 搜索 / 标签 / 聚合
- 用户登录与多用户
- 文件加密存储

## 六、详细需求

### 6.1 用户体验层

| # | 议题 | 决策 |
|---|---|---|
| 1 | 录音交互 | 「点一下开始、再点一下结束」，支持长时间录音 |
| 2 | 录完后操作 | 支持试听、重录、删除 |
| 3 | 上传状态可见性 | 提供一个独立的「上传列表」页面，展示成功 / 失败状态，不打扰当前录音过程 |
| 4 | 手机端历史查看 | 不需要在手机上查看历史碎片和日稿 |
| 5 | 日稿呈现方式 | 暂不确定，待后续再决定；不影响当前主流程 |

### 6.2 数据可靠性

| # | 议题 | 决策 |
|---|---|---|
| 1 | OSS 容量与积压 | 购买大容量 OSS（500G ~ 1T），允许积压；保证数据不丢 |
| 2 | 云端删除策略 | **不删除 OSS 上的文件**，本地只做下载，云端作为长期备份 |
| 3 | 去重和幂等 | 必须支持，避免重复转写 |
| 4 | 小程序本地缓存策略 | 一个语音上传成功（云端完整且正确备份）后即可删除；本地保留约 2 天兜底 |
| 5 | 失败重试策略 | 指数退避自动重试；**连续 3 次失败后切换为人工手动点击上传** |
| 6 | 网络差/缓存丢失兜底 | 默认录完立刻上传；离线进队列；上传列表页面用醒目标识"未上传 N 条，距离录音已 X 小时"；**网络差时强制等用户连网**，不允许长时间无网积压 |

### 6.3 隐私 / 安全

| # | 议题 | 决策 |
|---|---|---|
| 1 | OSS 密钥下发方式 | **采用阿里云函数计算 FC 签发 STS 临时凭证**（详见附录 A） |
| 2 | 录音加密 | 当前阶段不考虑 → **【下阶段计划 A】** 后续接入加密存储 |
| 3 | LLM 云端调用 | 接受将转写文本发送给云端大模型（本期不涉及，下一期执行） |
| 4 | 多用户与登录 | 当前阶段仅自己一人使用，不做登录 → **【下阶段计划 B】** 对外发布时再加 |

### 6.4 技术细节

| # | 议题 | 决策 |
|---|---|---|
| 1 | 微信小程序的硬限制 | 当前阶段先用小程序，后续如需突破限制再考虑 App |
| 2 | 转写方案 | **本地 Whisper large-v3 优先 + 抽象接口预留云端切换**：转写模块按 `Transcriber.transcribe(audio_path) -> text` 抽象，实现 `WhisperLocalTranscriber` 与 `AliyunCloudTranscriber` 两个适配器，通过配置开关切换 |
| 3 | 本地硬件 | Mac Studio，内存 128GB（运行 Whisper large-v3 性能富余） |
| 4 | 音频格式 | 统一保存为 **MP3**；不是 MP3 的需要转码 |
| 5 | 域名 | **全程使用阿里云自带的 HTTPS 域名**（OSS Bucket 域名、函数计算触发器域名），无需自购域名 |

## 七、整体架构

### 7.1 分层职责

| 层 | 组件 | 职责 |
|---|---|---|
| 手机端 | 微信小程序 | 录音、本地缓存、调用 FC 拿临时凭证、直传音频到 OSS、上传列表呈现 |
| 云端（无服务器） | 阿里云函数计算 FC | 接收小程序请求，调用 STS 签发 15 分钟临时凭证返回给小程序 |
| 云端（存储） | 阿里云 OSS（私有 Bucket）| 静默存储音频文件，无计算能力；作为长期备份 |
| 本地 | Python 脚本（Mac Studio） | 轮询 OSS → 下载新文件（不删云端）→ 去重幂等 → Whisper 转写 → 落盘到本地文件 |

### 7.3 数据可靠性闭环

> 问题：录完音直接上传，遇到网络切换或微信被杀后台，临时文件会永久丢失。

**解决方案**：在微信小程序内部建立「先落盘 → 排队上传 → 成功后销毁」的本地闭环。

- 利用微信小程序原生文件系统和本地缓存
- 手机端对自己产生的数据负责，直到云端签收为止
- 上传成功 = 云端文件完整且正确，才允许从本地清理
- 上传失败的 3 次自动重试 → 失败后转为人工手动上传
- 网络差时强制等待用户连网，不允许长时间无网积压

## 附录 A · 函数计算 FC + STS 实施流程概要

> 详细操作指引在动手实施时再展开，这里仅保留架构与步骤备忘。

### A.1 名词解释

| 名词 | 是什么 |
|---|---|
| **RAM 用户** | 阿里云子账号，类似"二级管理员"，可以单独授权 |
| **AccessKey (AK/SK)** | 一对长期密钥，权限大，**绝对不能放进小程序** |
| **STS** | 阿里云的"临时凭证签发服务"，给你颁发 15 分钟 ~ 1 小时有效的临时密钥 |
| **临时凭证** | 短期 AccessKey + SecretKey + SecurityToken 三件套，过期就废，泄露损失小 |
| **函数计算 FC** | 阿里云的 Serverless 服务，部署一段函数代码，给它一个 HTTPS URL，外部一调用就执行 |

### A.2 8 步实施清单

1. 开通阿里云账号 + 实名认证 + 充值
2. 开通 OSS，创建私有 Bucket（如 `soniscope-audio`）
3. RAM 创建专用子账号（仅授 `AliyunSTSAssumeRoleAccess`）
4. RAM 创建角色，权限策略限定为只能 `oss:PutObject` 到指定 Bucket
5. 开通函数计算 FC，编写约 30 行 Python 签发函数，配置环境变量
6. FC 配置 HTTP 触发器，得到自带 HTTPS 域名；将该域名 + OSS Bucket 域名加入微信小程序合法域名白名单
7. 小程序：调用 FC 拿临时凭证 → `wx.uploadFile` 直传 OSS
8. 本地 Python 脚本：用长期只读 AK 轮询 OSS → 下载 → Whisper 转写 → 落盘

### A.3 成本预估

| 项 | 月成本 |
|---|---|
| FC 调用 | ¥0（在免费额度内） |
| STS 调用 | ¥0（免费） |
| OSS 存储（1TB）| ~¥120 |
| 本地 Whisper | ¥0（自有硬件） |
| **合计** | **~¥120/月** |
