## Codebase Patterns
- 单一权威优先级：产品范围看 docs/PRD_v1.md，技术实现/schema/make target 看 docs/tech-spec.md，真实云资源/URL 看 docs/runbook/cloud-setup.md，开发红线看 AGENTS.md。冲突时按此优先级。
- Python 用 uv workspace：根 pyproject.toml 只声明 dev 工具（mypy/ruff/pytest）+ 引用本地成员 soniscope-worker，业务依赖（oss/pydantic/pyyaml/typer/nls）放 apps/worker/pyproject.toml。
- Worker 包采用 src 布局：apps/worker/src/soniscope_worker/，hatchling 打包，`[tool.hatch.build.targets.wheel] packages = ["src/soniscope_worker"]`。
- 顶层 Makefile 是唯一命令入口；所有命令用 `uv run ...` 执行，用户无需 cd 子目录。target 命名遵循 tech-spec §6.5。
- 质量门：`make typecheck`（mypy strict）、`make lint`（ruff，只查 apps/）、`make test`（pytest，testpaths=apps/worker/tests）。
- mypy/ruff/pytest 配置集中在根 pyproject.toml；mypy 用 files=apps/worker/{src,tests} + mypy_path + explicit_package_bases 适配 src 布局。
- 运行时数据目录与 repo 分离：$SONISCOPE_HOME（默认 ~/SoniScope），由 paths.py 解析；config.yaml、运行时目录、测试音频二进制均 gitignore，不进 git。
- 不要“修正”真实云资源里的拼写，尤其 issue-cedential-ottfirocds（少一个 r）。
- 遗留 scripts/test_asr.py 暂不纳入 lint（ruff 只查 apps/），由其归属 story 收口。
- scripts/ 下脚本「收口」模式（US-003 fetch_test_fixtures.py）：可测逻辑抽进 Worker 包（如 soniscope_worker/fixtures.py，自动被 mypy strict + ruff + pytest 覆盖），scripts/ 脚本作薄 CLU/IO 壳（OSS 下载等）复用之；脚本顶部 `sys.path.insert(0, REPO_ROOT/"apps/worker/src")` 后再 `from soniscope_worker... import`（带 `# noqa: E402`），使裸 `python3 scripts/xxx.py`（未装包）也能导入。
- fixture 校验：sha256 是唯一权威校验源（runbook §6），duration/codec 用 ffprobe 实测做 ±2s/容器编码的辅助校验；期望值数据驱动放 tests/audio/fixtures.manifest.json（duration_seconds 存 sha256 权威文件的实测时长，可能与文件名/runbook 标称值不同）。校验失败统一输出 fixtures.FIX_HINT 指向 runbook 第 6 节。
- 敏感字段脱敏：用 `MaskedSecret(SecretStr)` 子类重写 `_display()` 显示前后 4 位（`mask_secret`：>8 位显示首尾各 4，≤8 位整体打码）。Pydantic 自动把 str 验证成 MaskedSecret，业务侧用 `.get_secret_value()` 取明文，repr/str/日志只出脱敏摘要。
- make 命令优先做成 Worker CLI 子命令（typer），Makefile 只 `uv run python -m soniscope_worker <cmd>`；逻辑放 Python 便于 mypy/pytest 覆盖，CLI 失败用 `raise typer.Exit(code=1)` 保证非零退出。
- 配置加载：`load_config(path=None)` 默认走 `config_path()`，可注入路径便于测试；Pydantic ValidationError 用 `.errors()` 按 `type=="missing"` 汇总，一次性列全缺失字段（dotted loc）。
- mypy strict 下测试夹具参数用 `Mapping[str, object]`（covariant），不要用裸 `dict`/`dict[str, object]`（invariant 会报 arg-type）。
