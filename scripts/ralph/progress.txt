## Codebase Patterns
- Monorepo managed by uv workspace at the root — `pyproject.toml` only declares workspace members, no business deps.
- Worker is an independent uv sub-project under `apps/worker/` with its own `pyproject.toml` and `.venv`.
- `uv run --directory apps/worker <cmd>` as the standard invocation pattern from the project root.
- Makefile paths are relative to `apps/worker/` (e.g. `src/` not `apps/worker/src/`) because `uv run --directory apps/worker` changes CWD.
- mypy strict mode enforced from day one; `--strict` flag in Makefile.
- ruff for linting (not flake8 or pylint).
- pytest for testing; tests must exist — pytest exits with code 5 (failure) when no tests are collected.
- Pydantic v2 `model_validate()` is the canonical way to construct models from raw dicts.
- Secret masking: override `__repr__`, `__str__`, and `model_dump()` on Pydantic models; use a recursive `_mask_dict()` helper that knows which field names are sensitive.
- Config loading: `yaml.safe_load()` → `model_validate()` → catch `ValidationError` to extract and list all missing fields at once.
- Runtime dir initialization uses `Path.mkdir(parents=True, exist_ok=True)` for idempotent creation.
- `typer.Exit(code=1)` is how CLI commands signal non-zero exit; error messages go to stderr via `err=True` on `typer.echo()`.
- `typer.testing.CliRunner` is the standard way to test Typer CLI commands in pytest.
